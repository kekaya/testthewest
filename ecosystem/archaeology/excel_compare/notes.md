\- purpose: Compare two excel files

&#x20;

\- Install python

download and install https://www.python.org/downloads/ on windows

\- Install pandas openpyxl (pyxlsb for xlsb files)

&#x20; C:\\Users\\%USERNAME%\\AppData\\Local\\Python\\bin\\pip.exe install pandas openpyxl pyxlsb

&#x20;

\- put these files and directories to a place where you can drag and drop the two excel files you want to compare

&#x20;

ExcelCompare.bat --> This is where you drag and drop two excel files in

&#x20;

excel\_compare.py --> this is the script called from the ExcelCompare.bat

logs --> the folder where the logs are stored

&#x20;

openlogs.bat --> double click to open the logs directory

&#x20;

purge\_logs.bat --> empty the logs directory double clicking on the bat file

&#x20;

shell.bat --> open a command shell

&#x20;

testfiles --> this folder contains two test files which can be used for testing

&#x20;          to open the folder to access the test files



Same procedure for xlsb files under subdirectory xlsb
